## 🎯 Tentang Aplikasi

**Absensi App** adalah solusi presensi digital yang dirancang khusus untuk memudahkan proses absensi karyawan secara **real-time**, **akurat**, dan **bebas kecurangan**. Dibangun dengan Flutter, aplikasi ini berjalan mulus di Android dan iOS.

### 🚀 Keunggulan Utama
- ⚡ **Super Cepat** — Proses absensi kurang dari 5 detik
- 🔒 **Anti-Fraud** — Kombinasi GPS + Selfie + Timestamp
- 📱 **Cross Platform** — Android & iOS dalam satu codebase

---

## ✨ Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| ✅ **Presensi Real-time** | Absensi masuk & pulang dengan timestamp otomatis |
| 📍 **Geolokasi** | Validasi lokasi radius kantor saat absensi |
| 📸 **Selfie Camera** | Dokumentasi wajah + anti-spoofing detection |
| 📊 **Dashboard Statistik** | Rekap kehadiran harian, mingguan, bulanan |
| 🔔 **Notifikasi Cerdas** | Pengingat otomatis jam masuk & pulang |
| 👥 **Multi-role** | Admin & Karyawan dengan hak akses berbeda |
